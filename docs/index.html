Frequently Asked Questions

Everything you need to know about how Siphon runs on your machine.

How does Siphon connect to my Claude Code account? +

Siphon uses Anthropic's standard PKCE OAuth flow. It opens an ephemeral loopback port, directs your browser to Anthropic's authorization page, and safely captures the usage token — identical to how Claude Code authorizes.

Does Siphon replace Claude Code's terminal interface? +

No. Siphon is a companion tray monitor and floating widget, designed so you never have to type /cost or pause your work to check when your session resets.

Are my tokens and coding data safe? +

Yes. Siphon has no cloud servers, intermediate relays, or tracking telemetry. Your credentials are encrypted on your local machine using the native Windows DPAPI cipher.

How do the Windows reset notifications work? +

When your 5-hour session reaches 100%, Siphon reads the exact resets_at timestamp from Anthropic's API and schedules a native Windows toast notification to alert you the moment you are unblocked.

Which versions of Windows are supported? +

Siphon is built natively for Windows 10 and Windows 11 (64-bit), with full support for multi-monitor setups and varied DPI scaling.
